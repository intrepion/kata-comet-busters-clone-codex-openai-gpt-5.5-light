# Use 2D Canvas for Arcade Readability

Meteor Breakers will use a 2D Canvas presentation with crisp vector-inspired art and effects instead of 2.5D WebGL or a full 3D space arena. The genre's core skill is positional, rotational, and timing-based, so the first implementation should maximize readability and input feel before adding depth or camera complexity.

## Consequences

The visual bar is polish and clarity, not simulated spatial depth. Future 3D or WebGL effects must stay subordinate to the readable 2D playfield.
