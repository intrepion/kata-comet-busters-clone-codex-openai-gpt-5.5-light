# Wrap All Active Play Objects

Screen Wrap applies consistently to the Skimmer, Comets, Shards, and shots. A single wrapping rule keeps the playfield legible and preserves the classic pressure of threats and shots crossing edges.

## Consequences

Tests should verify wrap behavior for the Pilot, hazards, and projectiles. Any future non-wrapping object must be treated as an explicit exception rather than an accidental boundary rule.
