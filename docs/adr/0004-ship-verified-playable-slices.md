# Ship Verified Playable Slices

Meteor Breakers will be delivered through independently playable, verified MVP slices, with documentation captured before implementation and each implementation slice committed and pushed after verification. This matches the project's clone-delivery standard: a claim of completion requires browser evidence, not only code or build output.

## Consequences

Each slice should have a meaningful playable loop and a narrow verification gate. Direct-file launch must be tested as a real user-facing path rather than assumed from development-server success.
