# Keep Persistence and Hangar Small

The MVP will save only the Local Record: best score, best Wave, mute preference, and First Victory completion. The MVP Hangar will include start or restart, controls, best score, mute, and a victory marker, with no upgrade shop or complex run-state save.

## Consequences

The arcade loop stays focused on playfield feel. Future progression can be added deliberately, but it should not delay or obscure the first playable version.
