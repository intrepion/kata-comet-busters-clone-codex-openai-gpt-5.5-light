# Put Threat Readability Before Effects

Meteor Breakers will use Minimal Synth Arcade audio and polished visual effects, but hazards must always have Threat Priority over particles, stars, score popups, or Overdrive visuals. The player should never lose because spectacle obscured the actual danger.

## Consequences

Visual polish is accepted only when it supports play. Browser checks should include moments with shots, splits, and Overdrive active so readability is evaluated under noisy conditions, not only on a calm screen.
