# Start with Keyboard-First Controls

The first playable Meteor Breakers build will treat keyboard controls as first-class: rotation, thrust, and fire must feel good before gamepad, mouse aim, or touch controls are added. This keeps the earliest MVP focused on the classic control contract rather than spreading effort across multiple input surfaces.

## Consequences

The implementation should keep input mapping clean enough to extend, but MVP acceptance depends on keyboard play feeling correct in a real browser.
