# Build a Modern Arcade Homage

Meteor Breakers will be a modern arcade homage rather than an exact reproduction, a survival arena, a puzzle-action variant, or a full roguelite. The core contract remains classic: inertia, screen wrap, rotating fire, fragmenting Comets, lives, score pressure, and escalating Waves.

## Considered Options

- Near-classic vector arcade reproduction.
- Modern arcade homage.
- Survival arena with broader enemy pressure.
- Puzzle-action objective game.
- Roguelite with run upgrades and meta progression.

## Consequences

The game can use richer effects, readable UI, and carefully scoped modern conveniences, but every feature must protect the classic feel triangle of thrust, wraparound, and threat readability.
