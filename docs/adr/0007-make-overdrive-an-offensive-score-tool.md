# Make Overdrive an Offensive Score Tool

Overdrive will be an offensive score tool rather than a shield, bomb, or defensive escape. It is earned through skillful play such as near-misses and clean shooting, then spent as a short rapid-fire or piercing state that rewards staying engaged with danger.

## Consequences

Overdrive should intensify the arcade loop without erasing threat. If it becomes a universal safety button, it violates the intended risk-reward shape.
